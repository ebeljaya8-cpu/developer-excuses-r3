Entry for [Make the AI Judge Laugh: Developer Excuses](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3)
on [make.fun](https://make.fun): a program that writes one funny single-line
excuse a developer gives when code breaks in production, 200 characters at
most, to `/output/entry.txt`.

The line:

> The junior dev asked me to explain my code so I cried and whispered "it just works" for twenty minutes.

Run it with Node 22.18+:

```sh
node main.ts
```
